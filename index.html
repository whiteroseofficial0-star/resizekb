    Common questions

    How do I reduce a photo to 50 KB?

    Add the photo, choose File size mode, press the 50 KB shortcut, pick JPG and press Process. The result panel shows the measured size and whether the limit was met.

    My form wants exact pixels and a size range. What do I do?

    Choose Both, then enter width, height, minimum KB and maximum KB exactly as written. If the range cannot be reached at those pixels, the result says so instead of silently giving you a wrong file.

    Why did the tool say my size limit failed?

    Very small limits on large or detailed images can be impossible at the requested dimensions. Reduce the pixel size, switch to JPG or WebP, or increase the limit. The tool never claims a file passes when the measured bytes say otherwise.

    Can I resize several images at once?

    Yes. Select or drop multiple files, set the limits once, and press Process all. Each result is listed with its measured size, and the finished files can be downloaded together as a ZIP.

    How does cropping work?

    Press Crop, drag the box to move it, or drag a corner or edge handle to resize it. With Lock to output ratio on, the box follows the width and height you entered. The crop applies to the single image you are editing.

    Can I print my name and date on the photo?

    Yes. In Crop, rotate & stamp, tick Add a name / date stamp, type the name, choose a corner, size and colour, and optionally append today's date. The stamp is drawn at the output resolution with a soft halo for contrast, and it is included in batch results and PDFs too. Pick a dark colour for signatures on white paper and a light colour for photos.

    How do I share the exact limits with someone?

    Press Copy link in the presets card. The link stores the mode, width, height, KB range, format, fit, DPI and workflow in the part after #, so opening it fills those fields in automatically. It holds no image, no name and no account data, and the page never sends it anywhere.

    What does the DPI setting actually do?

    It writes a print-resolution tag (JFIF density for JPG, pHYs for PNG) so software and forms can read the intended DPI. It does not add pixels or improve detail — pick a resolution that matches the pixel size you need.

    Are my files uploaded?

    No. Decoding, cropping, compression and PDF creation happen in your browser. Only your presets and last-used settings are stored locally, and you can clear them by clearing site data.

    Are the presets official?

    No. ResizeKB is not affiliated with any government, exam body or portal. Built-in presets are examples only; always follow your own form's instructions.

    How it works and limits

    Files are decoded and re-encoded in your browser with the Canvas API. Magic bytes are checked, not just the file extension; files over 25 MB or 100 megapixels are rejected. File size is measured on the real output Blob. For a size target, JPG and WebP use a bounded binary search on quality, then scale down in steps when dimensions are free; PNG scales dimensions because it is lossless. An exact size is not always possible, and the result panel says so when it fails.

    Not included yet: multi-page PDFs, PDF merge/split, and DPI-aware physical size output.
